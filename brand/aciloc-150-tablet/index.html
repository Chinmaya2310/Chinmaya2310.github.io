What is the generic name of Aciloc 150?

Aciloc 150 contains Ranitidine 150 mg. Jan Aushadhi sells the same thing as “Ranitidine Tablets IP 150 mg”.

Can I take the Jan Aushadhi version instead of Aciloc 150?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

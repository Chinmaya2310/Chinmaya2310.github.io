What is the generic name of Acitrom 1?

Acitrom 1 contains Acenocoumarol 1 mg. Jan Aushadhi sells the same thing as “Nicoumalone/Acenocoumarol Tablets IP 1 mg”.

Can I take the Jan Aushadhi version instead of Acitrom 1?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

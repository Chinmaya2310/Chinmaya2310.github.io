What is the generic name of AF 150 DT?

AF 150 DT contains Fluconazole 150 mg. Jan Aushadhi sells the same thing as “Fluconazole Tablets IP 150 mg”.

Can I take the Jan Aushadhi version instead of AF 150 DT?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of AF 400?

AF 400 contains Fluconazole 400 mg. Jan Aushadhi sells the same thing as “Fluconazole Tablets IP 400 mg”.

Can I take the Jan Aushadhi version instead of AF 400?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Amitone 10mg?

Amitone 10mg contains Amitriptyline 10 mg. Jan Aushadhi sells the same thing as “Amitriptyline Hydrochloride Tablets IP 10mg”.

Can I take the Jan Aushadhi version instead of Amitone 10mg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

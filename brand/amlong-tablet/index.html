What is the generic name of Amlong?

Amlong contains Amlodipine 5 mg. Jan Aushadhi sells the same thing as “Amlodipine Tablets IP 5mg”.

Can I take the Jan Aushadhi version instead of Amlong?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

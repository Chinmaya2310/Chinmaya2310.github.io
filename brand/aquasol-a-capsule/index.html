What is the generic name of Aquasol A?

Aquasol A contains Vitamin A 25000 IU. Jan Aushadhi sells the same thing as “Vitamin A Capsule IP 25000 IU”.

Can I take the Jan Aushadhi version instead of Aquasol A?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Aquazide 12.5?

Aquazide 12.5 contains Hydrochlorothiazide 12.5 mg. Jan Aushadhi sells the same thing as “Hydrochlorothiazide Tablets IP 12.5mg”.

Can I take the Jan Aushadhi version instead of Aquazide 12.5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

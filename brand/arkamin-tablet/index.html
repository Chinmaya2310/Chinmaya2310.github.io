What is the generic name of Arkamin?

Arkamin contains Clonidine 100 mcg. Jan Aushadhi sells the same thing as “Clonidine Tablets IP 100 mcg”.

Can I take the Jan Aushadhi version instead of Arkamin?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Ciplactin?

Ciplactin contains Cyproheptadine 4 mg. Jan Aushadhi sells the same thing as “Cyproheptadine Tablets IP 4 mg”.

Can I take the Jan Aushadhi version instead of Ciplactin?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

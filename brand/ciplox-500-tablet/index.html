What is the generic name of Ciplox 500?

Ciplox 500 contains Ciprofloxacin 500 mg. Jan Aushadhi sells the same thing as “Ciprofloxacin Hydrochloride Tablets IP 500 mg”.

Can I take the Jan Aushadhi version instead of Ciplox 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

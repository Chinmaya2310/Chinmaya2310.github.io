What is the generic name of Clopilet?

Clopilet contains Clopidogrel 75 mg. Jan Aushadhi sells the same thing as “Clopidogrel Tablets IP 75mg”.

Can I take the Jan Aushadhi version instead of Clopilet?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

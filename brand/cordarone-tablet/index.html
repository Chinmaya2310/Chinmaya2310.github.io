What is the generic name of Cordarone?

Cordarone contains Amiodarone 100 mg. Jan Aushadhi sells the same thing as “Amiodarone Tablets IP 100 mg”.

Can I take the Jan Aushadhi version instead of Cordarone?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Drotin DS?

Drotin DS contains Drotaverine 80 mg. Jan Aushadhi sells the same thing as “Drotaverine Hydrochloride Tablets IP 80 mg”.

Can I take the Jan Aushadhi version instead of Drotin DS?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

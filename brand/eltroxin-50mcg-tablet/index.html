What is the generic name of Eltroxin 50mcg?

Eltroxin 50mcg contains Levothyroxine 50 mcg. Jan Aushadhi sells the same thing as “Thyroxine Sodium Tablets IP 50mcg”.

Can I take the Jan Aushadhi version instead of Eltroxin 50mcg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

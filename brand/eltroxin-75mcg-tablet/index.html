What is the generic name of Eltroxin 75mcg?

Eltroxin 75mcg contains Levothyroxine 75 mcg. Jan Aushadhi sells the same thing as “Thyroxine Sodium Tablets IP 75mcg”.

Can I take the Jan Aushadhi version instead of Eltroxin 75mcg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

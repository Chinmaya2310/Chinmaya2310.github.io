What is the generic name of Eptoin?

Eptoin contains Phenytoin 100 mg. Jan Aushadhi sells the same thing as “Phenytoin Tablets IP 100 mg”.

Can I take the Jan Aushadhi version instead of Eptoin?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

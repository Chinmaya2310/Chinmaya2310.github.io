What is the generic name of Eslo 5?

Eslo 5 contains S Amlodipine 5 mg. Jan Aushadhi sells the same thing as “S (-) Amlodipine Tablets IP 5mg”.

Can I take the Jan Aushadhi version instead of Eslo 5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

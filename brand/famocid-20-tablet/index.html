What is the generic name of Famocid 20?

Famocid 20 contains Famotidine 20 mg. Jan Aushadhi sells the same thing as “Famotidine Tablets IP 20 mg”.

Can I take the Jan Aushadhi version instead of Famocid 20?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

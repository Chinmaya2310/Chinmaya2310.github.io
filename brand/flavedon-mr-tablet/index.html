What is the generic name of Flavedon MR?

Flavedon MR contains Trimetazidine 35 mg (SR). Jan Aushadhi sells the same thing as “Trimetazidine Hydrochloride Modified Release Tablets 35 mg”.

Can I take the Jan Aushadhi version instead of Flavedon MR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

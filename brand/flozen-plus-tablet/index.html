What is the generic name of Flozen-Plus?

Flozen-Plus contains Diclofenac 50 mg + Paracetamol 325 mg. Jan Aushadhi sells the same thing as “Diclofenac Sodium 50mg and Paracetamol 325mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Flozen-Plus?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

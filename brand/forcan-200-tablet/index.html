What is the generic name of Forcan 200?

Forcan 200 contains Fluconazole 200 mg. Jan Aushadhi sells the same thing as “Fluconazole Tablets IP 200 mg”.

Can I take the Jan Aushadhi version instead of Forcan 200?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

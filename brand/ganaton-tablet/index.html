What is the generic name of Ganaton?

Ganaton contains Itopride 50 mg. Jan Aushadhi sells the same thing as “Itopride Tablets IP 50 mg”.

Can I take the Jan Aushadhi version instead of Ganaton?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

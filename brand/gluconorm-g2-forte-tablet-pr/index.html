What is the generic name of Gluconorm G2 Forte PR?

Gluconorm G2 Forte PR contains Glimepiride 2 mg + Metformin 1 g (SR). Jan Aushadhi sells the same thing as “Metformin Hydrochloride 1000mg (Prolonged Release) and Glimepiride 2mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Gluconorm G2 Forte PR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

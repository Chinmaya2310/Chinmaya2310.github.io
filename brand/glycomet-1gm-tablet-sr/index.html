What is the generic name of Glycomet 1gm SR?

Glycomet 1gm SR contains Metformin 1 g (SR). Jan Aushadhi sells the same thing as “Metformin Hydrochloride Sustained Release Tablets IP 1000 mg”.

Can I take the Jan Aushadhi version instead of Glycomet 1gm SR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

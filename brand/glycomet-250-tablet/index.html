What is the generic name of Glycomet 250?

Glycomet 250 contains Metformin 250 mg. Jan Aushadhi sells the same thing as “Metformin Hydrochloride Tablets IP 250 mg”.

Can I take the Jan Aushadhi version instead of Glycomet 250?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

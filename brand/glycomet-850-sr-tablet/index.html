What is the generic name of Glycomet 850 SR?

Glycomet 850 SR contains Metformin 850 mg (SR). Jan Aushadhi sells the same thing as “Metformin Sustained Release Tablets IP 850mg”.

Can I take the Jan Aushadhi version instead of Glycomet 850 SR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

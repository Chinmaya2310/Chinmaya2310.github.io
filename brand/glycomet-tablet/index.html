What is the generic name of Glycomet?

Glycomet contains Metformin 500 mg. Jan Aushadhi sells the same thing as “Metformin Hydrochloride Tablets IP 500mg”.

Can I take the Jan Aushadhi version instead of Glycomet?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

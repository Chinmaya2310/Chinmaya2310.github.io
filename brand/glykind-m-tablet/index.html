What is the generic name of Glykind-M?

Glykind-M contains Gliclazide 80 mg + Metformin 500 mg. Jan Aushadhi sells the same thing as “Gliclazide 80mg and Metformin Hydrochloride 500mg Tablets”.

Can I take the Jan Aushadhi version instead of Glykind-M?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Glynase?

Glynase contains Glipizide 5 mg. Jan Aushadhi sells the same thing as “Glipizide Tablet IP 5 mg”.

Can I take the Jan Aushadhi version instead of Glynase?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

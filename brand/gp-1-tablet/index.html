What is the generic name of GP 1?

GP 1 contains Glimepiride 1 mg. Jan Aushadhi sells the same thing as “Glimepiride Tablets IP 1mg”.

Can I take the Jan Aushadhi version instead of GP 1?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

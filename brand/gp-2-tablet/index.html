What is the generic name of GP 2?

GP 2 contains Glimepiride 2 mg. Jan Aushadhi sells the same thing as “Glimepiride Tablets IP 2mg”.

Can I take the Jan Aushadhi version instead of GP 2?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

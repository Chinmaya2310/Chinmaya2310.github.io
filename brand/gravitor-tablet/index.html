What is the generic name of Gravitor?

Gravitor contains Pyridostigmine 60 mg. Jan Aushadhi sells the same thing as “Pyridostigmine Bromide Tablets IP 60mg”.

Can I take the Jan Aushadhi version instead of Gravitor?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

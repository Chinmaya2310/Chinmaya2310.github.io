What is the generic name of Gris ODT?

Gris ODT contains Terbinafine 250 mg. Jan Aushadhi sells the same thing as “Terbinafine Tablets IP 250mg”.

Can I take the Jan Aushadhi version instead of Gris ODT?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

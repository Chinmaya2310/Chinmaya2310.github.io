What is the generic name of HYQ 400?

HYQ 400 contains Hydroxychloroquine 400 mg. Jan Aushadhi sells the same thing as “Hydroxychloroquine Tablet IP 400 mg”.

Can I take the Jan Aushadhi version instead of HYQ 400?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

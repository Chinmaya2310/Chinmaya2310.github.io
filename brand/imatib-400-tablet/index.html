Imatib 400 contains Imatinib 400 mg. Jan Aushadhi sells the same thing as “Imatinib Mesylate Tablets IP 400mg”.

Can I take the Jan Aushadhi version instead of Imatib 400?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

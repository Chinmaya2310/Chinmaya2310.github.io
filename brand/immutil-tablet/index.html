What is the generic name of Immutil?

Immutil contains Mycophenolate Mofetil 500 mg. Jan Aushadhi sells the same thing as “Mycophenolate Mofetil Tablets IP 500mg”.

Can I take the Jan Aushadhi version instead of Immutil?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

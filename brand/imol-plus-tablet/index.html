What is the generic name of Imol Plus?

Imol Plus contains Ibuprofen 400 mg + Paracetamol 325 mg. Jan Aushadhi sells the same thing as “Ibuprofen 400mg and Paracetamol 325mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Imol Plus?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

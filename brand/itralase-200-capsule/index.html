What is the generic name of Itralase 200?

Itralase 200 contains Itraconazole 200 mg. Jan Aushadhi sells the same thing as “Itraconazole Capsules 200 mg”.

Can I take the Jan Aushadhi version instead of Itralase 200?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

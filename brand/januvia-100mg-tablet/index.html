What is the generic name of Januvia 100mg?

Januvia 100mg contains Sitagliptin 100 mg. Jan Aushadhi sells the same thing as “Sitagliptin Phosphate Tablets IP 100mg”.

Can I take the Jan Aushadhi version instead of Januvia 100mg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Jimlig 100?

Jimlig 100 contains Itraconazole 100 mg. Jan Aushadhi sells the same thing as “Itraconazole Capsules 100 mg”.

Can I take the Jan Aushadhi version instead of Jimlig 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Joten M-Forte ER?

Joten M-Forte ER contains Metformin 1 g + Teneligliptin 20 mg (SR). Jan Aushadhi sells the same thing as “Teneligliptin 20mg and Metformin Hydrochloride 1000mg (Sustained Release) Tablets IP”.

Can I take the Jan Aushadhi version instead of Joten M-Forte ER?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

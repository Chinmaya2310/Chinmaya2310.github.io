What is the generic name of Kinpride?

Kinpride contains Cinitapride 1 mg. Jan Aushadhi sells the same thing as “Cinitapride Tablets 1 mg”.

Can I take the Jan Aushadhi version instead of Kinpride?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Lacoset 100?

Lacoset 100 contains Lacosamide 100 mg. Jan Aushadhi sells the same thing as “Lacosamide Tablets 100mg”.

Can I take the Jan Aushadhi version instead of Lacoset 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Lesuride?

Lesuride contains Levosulpiride 25 mg. Jan Aushadhi sells the same thing as “Levosulpiride Tablets 25mg”.

Can I take the Jan Aushadhi version instead of Lesuride?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

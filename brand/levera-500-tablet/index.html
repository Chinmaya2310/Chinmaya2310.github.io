What is the generic name of Levera 500?

Levera 500 contains Levetiracetam 500 mg. Jan Aushadhi sells the same thing as “Levetiracetam Tablets IP 500 mg”.

Can I take the Jan Aushadhi version instead of Levera 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

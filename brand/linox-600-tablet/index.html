What is the generic name of Linox 600?

Linox 600 contains Linezolid 600 mg. Jan Aushadhi sells the same thing as “Linezolid Tablets IP 600 mg”.

Can I take the Jan Aushadhi version instead of Linox 600?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

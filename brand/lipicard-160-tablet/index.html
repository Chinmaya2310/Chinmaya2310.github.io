What is the generic name of Lipicard 160?

Lipicard 160 contains Fenofibrate 160 mg. Jan Aushadhi sells the same thing as “Fenofibrate Tablets IP 160 mg”.

Can I take the Jan Aushadhi version instead of Lipicard 160?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

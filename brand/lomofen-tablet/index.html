What is the generic name of Lomofen?

Lomofen contains Atropine 25 mcg + Diphenoxylate 2.5 mg. Jan Aushadhi sells the same thing as “Diphenoxylate Hydrochloride 2.5mg and Atropine sulphate 0.025mg Tablet”.

Can I take the Jan Aushadhi version instead of Lomofen?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Macpod CV 200?

Macpod CV 200 contains Cefpodoxime 200 mg + Clavulanic Acid 125 mg. Jan Aushadhi sells the same thing as “Cefpodoxime 200mg and Potassium Clavulanate 125mg Tablets”.

Can I take the Jan Aushadhi version instead of Macpod CV 200?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Meftal 500?

Meftal 500 contains Mefenamic Acid 500 mg. Jan Aushadhi sells the same thing as “Mefenamic Acid Tablets 500 mg”.

Can I take the Jan Aushadhi version instead of Meftal 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Metosartan 50 ER?

Metosartan 50 ER contains Metoprolol Succinate 50 mg + Telmisartan 40 mg (SR). Jan Aushadhi sells the same thing as “Metoprolol Succinate 50mg (Extended Release) and Telmisartan 40mg Tablets”.

Can I take the Jan Aushadhi version instead of Metosartan 50 ER?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

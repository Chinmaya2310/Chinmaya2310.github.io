What is the generic name of Metsmall 500 SR?

Metsmall 500 SR contains Metformin 500 mg (SR). Jan Aushadhi sells the same thing as “Metformin Hydrochloride Prolonged release Tablets IP 500 mg”.

Can I take the Jan Aushadhi version instead of Metsmall 500 SR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

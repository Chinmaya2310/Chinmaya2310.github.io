What is the generic name of Montas-L?

Montas-L contains Levocetirizine 5 mg + Montelukast 10 mg. Jan Aushadhi sells the same thing as “Montelukast Sodium 10mg and Levocetirizine 5mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Montas-L?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

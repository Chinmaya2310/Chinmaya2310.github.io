What is the generic name of Mox CV 625?

Mox CV 625 contains Amoxicillin 500 mg + Clavulanic Acid 125 mg. Jan Aushadhi sells the same thing as “Amoxycillin 500mg and Potassium Clavulanate 125mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Mox CV 625?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

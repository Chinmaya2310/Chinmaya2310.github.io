What is the generic name of Nebicard 5?

Nebicard 5 contains Nebivolol 5 mg. Jan Aushadhi sells the same thing as “Nebivolol Tablets IP 5 mg”.

Can I take the Jan Aushadhi version instead of Nebicard 5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

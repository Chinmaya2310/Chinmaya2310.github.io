What is the generic name of Nicip?

Nicip contains Nimesulide 100 mg. Jan Aushadhi sells the same thing as “Nimesulide Tablets 100 mg”.

Can I take the Jan Aushadhi version instead of Nicip?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

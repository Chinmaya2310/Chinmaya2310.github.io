What is the generic name of Nodosis?

Nodosis contains Sodium Bicarbonate 500 mg. Jan Aushadhi sells the same thing as “Sodium Bicarbonate Tablet 500 mg”.

Can I take the Jan Aushadhi version instead of Nodosis?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

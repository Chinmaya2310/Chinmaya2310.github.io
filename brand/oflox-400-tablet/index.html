What is the generic name of Oflox 400?

Oflox 400 contains Ofloxacin 400 mg. Jan Aushadhi sells the same thing as “Ofloxacin Tablets IP 400mg”.

Can I take the Jan Aushadhi version instead of Oflox 400?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

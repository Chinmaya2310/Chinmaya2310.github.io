What is the generic name of Omez?

Omez contains Omeprazole 20 mg. Jan Aushadhi sells the same thing as “Omeprazole Gastro-resistant Capsules IP 20 mg”.

Can I take the Jan Aushadhi version instead of Omez?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

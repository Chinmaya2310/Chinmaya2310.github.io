What is the generic name of Oxcarb 300?

Oxcarb 300 contains Oxcarbazepine 300 mg. Jan Aushadhi sells the same thing as “Oxcarbazepine Tablets IP 300mg”.

Can I take the Jan Aushadhi version instead of Oxcarb 300?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of PAN 20?

PAN 20 contains Pantoprazole 20 mg. Jan Aushadhi sells the same thing as “Pantoprazole Gastro-Resistance Tablets IP 20mg”.

Can I take the Jan Aushadhi version instead of PAN 20?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

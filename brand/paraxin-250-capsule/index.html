What is the generic name of Paraxin 250?

Paraxin 250 contains Chloramphenicol 250 mg. Jan Aushadhi sells the same thing as “Chloramphenicol Capsules IP 250 mg”.

Can I take the Jan Aushadhi version instead of Paraxin 250?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

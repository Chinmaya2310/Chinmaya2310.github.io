What is the generic name of Pari CR 12.5?

Pari CR 12.5 contains Paroxetine 12.5 mg (SR). Jan Aushadhi sells the same thing as “Paroxetine Prolonged-release Tablets IP 12.5mg”.

Can I take the Jan Aushadhi version instead of Pari CR 12.5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Pause 500?

Pause 500 contains Tranexamic Acid 500 mg. Jan Aushadhi sells the same thing as “Tranexamic Acid Tablets IP 500 mg”.

Can I take the Jan Aushadhi version instead of Pause 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

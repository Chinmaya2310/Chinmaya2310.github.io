What is the generic name of Perinorm?

Perinorm contains Metoclopramide 10 mg. Jan Aushadhi sells the same thing as “Metoclopramide Tablets IP 10 mg”.

Can I take the Jan Aushadhi version instead of Perinorm?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

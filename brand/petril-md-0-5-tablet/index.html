What is the generic name of Petril-MD 0.5?

Petril-MD 0.5 contains Clonazepam 500 mcg. Jan Aushadhi sells the same thing as “Clonazepam Tablets IP 0.5 mg”.

Can I take the Jan Aushadhi version instead of Petril-MD 0.5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

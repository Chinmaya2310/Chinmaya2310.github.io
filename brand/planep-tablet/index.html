What is the generic name of Planep?

Planep contains Eplerenone 25 mg. Jan Aushadhi sells the same thing as “Eplerenone Tablets IP 25 mg”.

Can I take the Jan Aushadhi version instead of Planep?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

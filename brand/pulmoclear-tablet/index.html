What is the generic name of Pulmoclear ?

Pulmoclear contains Acebrophylline 100 mg + Acetylcysteine 600 mg. Jan Aushadhi sells the same thing as “Acebrophylline 100mg and Acetylcysteine 600mg Tablets”.

Can I take the Jan Aushadhi version instead of Pulmoclear ?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

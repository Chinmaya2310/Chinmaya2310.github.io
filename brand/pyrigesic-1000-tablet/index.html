What is the generic name of Pyrigesic 1000?

Pyrigesic 1000 contains Paracetamol 1 g. Jan Aushadhi sells the same thing as “Paracetamol Tablets IP 1000 Mg”.

Can I take the Jan Aushadhi version instead of Pyrigesic 1000?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Rancad ER?

Rancad ER contains Ranolazine 500 mg (SR). Jan Aushadhi sells the same thing as “Ranolazine Extended Release Tablets 500mg”.

Can I take the Jan Aushadhi version instead of Rancad ER?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

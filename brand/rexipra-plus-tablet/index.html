What is the generic name of Rexipra Plus?

Rexipra Plus contains Clonazepam 500 mcg + Escitalopram Oxalate 5 mg. Jan Aushadhi sells the same thing as “Escitalopram Oxalate 5mg and Clonazepam 0.5mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Rexipra Plus?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

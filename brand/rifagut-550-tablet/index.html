What is the generic name of Rifagut 550?

Rifagut 550 contains Rifaximin 550 mg. Jan Aushadhi sells the same thing as “Rifaximin Tablets 550 mg”.

Can I take the Jan Aushadhi version instead of Rifagut 550?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

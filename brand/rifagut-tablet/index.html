What is the generic name of Rifagut?

Rifagut contains Rifaximin 200 mg. Jan Aushadhi sells the same thing as “Rifaximin Tablets 200 mg”.

Can I take the Jan Aushadhi version instead of Rifagut?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of ROKO?

ROKO contains Loperamide 2 mg. Jan Aushadhi sells the same thing as “Loperamide Capsules IP 2 mg”.

Can I take the Jan Aushadhi version instead of ROKO?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

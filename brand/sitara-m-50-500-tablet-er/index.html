What is the generic name of Sitara-M 50/500 ER?

Sitara-M 50/500 ER contains Metformin 500 mg + Sitagliptin 50 mg (SR). Jan Aushadhi sells the same thing as “Sitagliptin 50mg and Metformin 500mg Extended Release Tablets”.

Can I take the Jan Aushadhi version instead of Sitara-M 50/500 ER?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

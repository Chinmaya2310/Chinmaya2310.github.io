What is the generic name of Strocit 500?

Strocit 500 contains Citicoline 500 mg. Jan Aushadhi sells the same thing as “Citicoline Tablets IP 500mg”.

Can I take the Jan Aushadhi version instead of Strocit 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Suhagra 50?

Suhagra 50 contains Sildenafil 50 mg. Jan Aushadhi sells the same thing as “Sildenafil Tablets IP 50 mg”.

Can I take the Jan Aushadhi version instead of Suhagra 50?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

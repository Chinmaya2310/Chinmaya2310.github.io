What is the generic name of Tadaflo 5?

Tadaflo 5 contains Tadalafil 5 mg. Jan Aushadhi sells the same thing as “Tadalafil Tablets IP 5 mg”.

Can I take the Jan Aushadhi version instead of Tadaflo 5?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

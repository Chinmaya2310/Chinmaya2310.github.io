What is the generic name of Taxim-O 200?

Taxim-O 200 contains Cefixime 200 mg. Jan Aushadhi sells the same thing as “Cefixime Tablets IP 200 mg”.

Can I take the Jan Aushadhi version instead of Taxim-O 200?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

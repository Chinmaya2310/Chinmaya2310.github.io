What is the generic name of Telmikind 20?

Telmikind 20 contains Telmisartan 20 mg. Jan Aushadhi sells the same thing as “Telmisartan Tablets IP 20mg”.

Can I take the Jan Aushadhi version instead of Telmikind 20?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

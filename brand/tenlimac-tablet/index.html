What is the generic name of Tenlimac?

Tenlimac contains Teneligliptin 20 mg. Jan Aushadhi sells the same thing as “Teneligliptin Tablets IP 20mg”.

Can I take the Jan Aushadhi version instead of Tenlimac?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

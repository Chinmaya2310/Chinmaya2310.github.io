What is the generic name of Texakind-MF?

Texakind-MF contains Mefenamic Acid 250 mg + Tranexamic Acid 500 mg. Jan Aushadhi sells the same thing as “Tranexamic Acid 500mg and Mefenamic Acid 250mg Tablets”.

Can I take the Jan Aushadhi version instead of Texakind-MF?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

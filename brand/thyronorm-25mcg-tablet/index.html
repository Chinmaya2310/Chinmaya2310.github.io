What is the generic name of Thyronorm 25mcg?

Thyronorm 25mcg contains Levothyroxine 25 mcg. Jan Aushadhi sells the same thing as “Thyroxine Sodium Tablets IP 25mcg”.

Can I take the Jan Aushadhi version instead of Thyronorm 25mcg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

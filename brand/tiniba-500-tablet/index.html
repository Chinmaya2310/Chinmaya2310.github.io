What is the generic name of Tiniba 500?

Tiniba 500 contains Tinidazole 500 mg. Jan Aushadhi sells the same thing as “Tinidazole Tablets IP 500 mg”.

Can I take the Jan Aushadhi version instead of Tiniba 500?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

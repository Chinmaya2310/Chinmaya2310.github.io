What is the generic name of Tolperitas 150?

Tolperitas 150 contains Tolperisone 150 mg. Jan Aushadhi sells the same thing as “Tolperisone Tablet 150mg”.

Can I take the Jan Aushadhi version instead of Tolperitas 150?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

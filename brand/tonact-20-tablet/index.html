What is the generic name of Tonact 20?

Tonact 20 contains Atorvastatin 20 mg. Jan Aushadhi sells the same thing as “Atorvastatin Tablets IP 20mg”.

Can I take the Jan Aushadhi version instead of Tonact 20?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

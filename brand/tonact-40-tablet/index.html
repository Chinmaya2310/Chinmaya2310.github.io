What is the generic name of Tonact 40?

Tonact 40 contains Atorvastatin 40 mg. Jan Aushadhi sells the same thing as “Atorvastatin Tablets IP 40 mg”.

Can I take the Jan Aushadhi version instead of Tonact 40?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Trika 0.25mg?

Trika 0.25mg contains Alprazolam 250 mcg. Jan Aushadhi sells the same thing as “Alprazolam Tablets IP 0.25 mg”.

Can I take the Jan Aushadhi version instead of Trika 0.25mg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Udiliv 150mg?

Udiliv 150mg contains Ursodeoxycholic Acid 150 mg. Jan Aushadhi sells the same thing as “Ursodeoxycholic Acid Tablets IP 150mg”.

Can I take the Jan Aushadhi version instead of Udiliv 150mg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

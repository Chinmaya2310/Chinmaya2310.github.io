What is the generic name of Uprise-D3 60K?

Uprise-D3 60K contains Vitamin D3 60000 IU. Jan Aushadhi sells the same thing as “Cholecalciferol Soft Gelatin Capsule 60000 IU”.

Can I take the Jan Aushadhi version instead of Uprise-D3 60K?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

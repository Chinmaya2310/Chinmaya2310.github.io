What is the generic name of Uvox 100?

Uvox 100 contains Fluvoxamine 100 mg. Jan Aushadhi sells the same thing as “Fluvoxamine Maleate Tablets IP 100mg”.

Can I take the Jan Aushadhi version instead of Uvox 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

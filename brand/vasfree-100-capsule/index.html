What is the generic name of Vasfree 100?

Vasfree 100 contains Flupirtine 100 mg. Jan Aushadhi sells the same thing as “Flupirtine Maleate Capsules 100mg”.

Can I take the Jan Aushadhi version instead of Vasfree 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

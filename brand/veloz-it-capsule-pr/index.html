What is the generic name of Veloz IT PR?

Veloz IT PR contains Itopride 150 mg + Rabeprazole 20 mg (SR). Jan Aushadhi sells the same thing as “Rabeprazole Sodium (Gastro-resistant) 20mg and Itopride Hydrochloride Prolonged release 150mg Capsules IP”.

Can I take the Jan Aushadhi version instead of Veloz IT PR?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

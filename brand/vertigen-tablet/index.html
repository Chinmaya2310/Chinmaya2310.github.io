What is the generic name of Vertigen?

Vertigen contains Cinnarizine 20 mg + Dimenhydrinate 40 mg. Jan Aushadhi sells the same thing as “Cinnarizine 20mg and Dimenhydrinate 40mg Tablets”.

Can I take the Jan Aushadhi version instead of Vertigen?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

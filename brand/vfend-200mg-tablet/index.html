What is the generic name of Vfend 200mg?

Vfend 200mg contains Voriconazole 200 mg. Jan Aushadhi sells the same thing as “Voriconazole Tablets IP 200mg”.

Can I take the Jan Aushadhi version instead of Vfend 200mg?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

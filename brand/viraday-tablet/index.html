What is the generic name of Viraday?

Viraday contains Emtricitabine 200 mg + Tenofovir Disoproxil 300 mg. Jan Aushadhi sells the same thing as “Emtricitabine 200mg and Tenofovir Disoproxil Fumarate 300mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Viraday?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

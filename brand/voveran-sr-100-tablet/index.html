What is the generic name of Voveran SR 100?

Voveran SR 100 contains Diclofenac 100 mg (SR). Jan Aushadhi sells the same thing as “Diclofenac Sodium Prolonged Release Tablets IP 100 mg”.

Can I take the Jan Aushadhi version instead of Voveran SR 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Walacort?

Walacort contains Betamethasone 500 mcg. Jan Aushadhi sells the same thing as “Betamethasone Sodium Phosphate Tablets IP 0.5 mg”.

Can I take the Jan Aushadhi version instead of Walacort?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

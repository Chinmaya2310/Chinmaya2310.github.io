What is the generic name of Xstan-H?

Xstan-H contains Hydrochlorothiazide 12.5 mg + Telmisartan 40 mg. Jan Aushadhi sells the same thing as “Telmisartan 40mg and Hydrochlorothiazide 12.5mg Tablets IP”.

Can I take the Jan Aushadhi version instead of Xstan-H?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

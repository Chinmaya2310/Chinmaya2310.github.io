What is the generic name of Zady 250?

Zady 250 contains Azithromycin 250 mg. Jan Aushadhi sells the same thing as “Azithromycin Tablets IP 250 mg”.

Can I take the Jan Aushadhi version instead of Zady 250?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

What is the generic name of Zeebee?

Zeebee contains Albendazole 400 mg. Jan Aushadhi sells the same thing as “Albendazole Tablets IP 400mg”.

Can I take the Jan Aushadhi version instead of Zeebee?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

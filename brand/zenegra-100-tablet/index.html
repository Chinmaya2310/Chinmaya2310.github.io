What is the generic name of Zenegra 100?

Zenegra 100 contains Sildenafil 100 mg. Jan Aushadhi sells the same thing as “Sildenafil Tablets IP 100 mg”.

Can I take the Jan Aushadhi version instead of Zenegra 100?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

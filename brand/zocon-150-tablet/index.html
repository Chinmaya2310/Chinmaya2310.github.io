What is the generic name of Zocon 150?

Zocon 150 contains Fluconazole 150 mg. Jan Aushadhi sells the same thing as “Fluconazole Tablets IP 150 mg”.

Can I take the Jan Aushadhi version instead of Zocon 150?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

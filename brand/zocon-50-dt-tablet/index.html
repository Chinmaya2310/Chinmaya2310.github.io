What is the generic name of Zocon 50 DT?

Zocon 50 DT contains Fluconazole 50 mg. Jan Aushadhi sells the same thing as “Fluconazole Tablets IP 50 mg”.

Can I take the Jan Aushadhi version instead of Zocon 50 DT?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.

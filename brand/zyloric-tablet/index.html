What is the generic name of Zyloric?

Zyloric contains Allopurinol 100 mg. Jan Aushadhi sells the same thing as “Allopurinol Tablets IP 100 mg”.

Can I take the Jan Aushadhi version instead of Zyloric?

It has the same salt in the same strength, so it should work the same way. Ask your doctor or pharmacist before switching.
